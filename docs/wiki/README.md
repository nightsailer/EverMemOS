### 01 - 核心框架

**核心内容**：
- DI依赖注入容器（IoC、装饰器、组件扫描）

- 上下文管理（ContextVar三层设计）

- 生命周期管理（LifespanProvider）

- 限流（协程级限流）
- NLP工具（停用词管理）

**关键设计**：
- Bean生命周期（SINGLETON/PROTOTYPE/FACTORY）
- Primary机制（多实现自动选择）
- Mock支持（测试友好）
- ContextVar线程安全设计
- Lua脚本原子性保证

**适合人群**：后端开发者、架构师

### 02 - 数据存储与ORM

**核心内容**：
- MongoDB集成（Beanie ODM、事务管理）
- Elasticsearch集成（BM25检索、中文分词）
- Milvus集成（向量检索、HNSW索引）
- Redis集成（连接池、命名客户端）
- ORM抽象层（统一接口设计）
- Converter转换器（格式转换）
- 数据一致性（三层同步策略）

**关键文档模型**：
- CoreMemory（用户档案）
- EpisodicMemory（情景记忆）
- SemanticMemory（语义记忆）

**关键设计**：
- 异构存储策略（各数据库发挥所长）
- 别名索引模式（ES/Milvus版本切换）
- 审计字段自动填充（AuditBase）
- 时区统一处理（UTC）

**适合人群**：数据库工程师、后端开发者

---

### 03 - 记忆管理系统

**核心内容**：
- MemCell提取器（LLM边界检测）
- Memory提取器（5种记忆类型）
- 聚类管理器（增量质心聚类）
- 画像管理器（价值判别+版本控制）
- Agentic Layer检索（5种策略）
- RRF融合算法（多源检索合并）
- Agentic检索（LLM多轮智能检索）
- 向量化服务（DeepInfra Embedding）
- 重排序服务（DeepInfra Rerank）
- LLM集成（OpenAI Provider）
- 提示词工程（多语言支持）

**核心算法**：
- 对话边界检测（"默认合并，谨慎切分"）
- 增量质心聚类（递推平均）
- RRF融合（Reciprocal Rank Fusion）
- 多查询RRF（Agentic检索核心）

**关键设计**：
- 5种Memory类型全面覆盖
- LLM深度集成（边界检测、提取、检索）
- 向量化+文本检索双引擎
- 提示词工程精心设计

**适合人群**：算法工程师、AI开发者

---

### 04 - API与适配器

**核心内容**：
- API V2（7个端点、细粒度控制）
- API V3（3个端点、群聊优化）
- 六边形架构（输入/输出适配器）
- 格式转换器（Converters）
- 错误处理（全局异常处理器）
- 性能优化（缓存+批处理）

**V2 vs V3对比**：
- 目标场景差异
- 消息格式差异
- 检索策略差异
- 性能特点差异

**关键设计**：
- 单一职责原则（适配器仅负责格式转换）
- 依赖倒置（核心业务不依赖适配器）
- 接口隔离（每个适配器独立接口）

**适合人群**：前端开发者、API集成者
